# ZombieHorde

使用 **Godot 4 + GDScript** 开发的 2D 俯视角丧尸生存游戏。玩家在尸群中移动、射击、收集经验，通过三选一强化逐步提升战斗能力，并挑战精英与首领。

项目目前处于原型开发阶段，包含可运行的游戏工程、角色与界面素材，以及自动游玩和压力测试入口。

## 游戏内容

- **生存战斗**：支持自动索敌开火和鼠标手动射击，搭配奔跑与闪避。
- **角色成长**：收集经验升级，从三张强化卡中选择一项；强化包含伤害、多发、穿透、暴击和吸附范围等。
- **敌人与首领**：包含普通丧尸、撕裂者、喷吐者、重锤、溺亡者，以及带阶段变化和独立血条的 Boss。
- **波次推进**：每波 25 秒，每 5 波出现精英，每 10 波出现首领，敌人属性与生成频率随波次提高。
- **地图互动**：包含水域、减速、浮出预警，以及废车、路障、围栏等场景装饰。
- **补给与商店**：包含宝箱、手雷、生命药水、复活药剂、开局强化和行囊扩容，商店同类商品价格随购买次数上涨。
- **本地存档**：保存最佳记录、金币和商店相关进度。

## 如何运行

### 环境

- Godot 编辑器：工程配置声明版本为 **4.7**，渲染配置为 **Forward Plus**。
- 脚本使用 GDScript，无需 .NET 版本编辑器。
- 默认视口为 **1280 × 720**。

### 启动步骤

1. 下载本仓库 ZIP 并解压，或使用 Git 克隆：

   ```sh
   git clone https://github.com/carolnicholson141-debug/-.git zombie-horde
   ```

2. 打开 Godot 项目管理器，点击“导入”。
3. 选择项目根目录下的 `project.godot`，等待素材导入完成。
4. 在编辑器中按 **F5** 运行项目，点击开始按钮进入游戏。

主场景为 `scenes/main.tscn`。角色动画使用 `AnimatedSprite2D` 和图片帧，运行当前游戏无需安装 Blender 或 Spine。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| W / A / S / D 或方向键 | 移动 |
| Shift | 切换行走 / 奔跑，再按一次切回 |
| 空格 | 闪避 |
| F | 切换自动 / 手动开火 |
| 鼠标移动 + 按住左键 | 手动模式下瞄准并射击 |
| 数字键 1–5 | 使用对应行囊栏位的物品，需先拥有并解锁栏位 |
| Esc | 游戏中暂停 / 继续 |
| R | 死亡后重新开始 |
| F3 | 切换调试信息 |

默认使用自动开火模式。复活药剂作为被动充能，在角色倒下时自动触发。

## 项目结构

| 目录或文件 | 内容 |
| --- | --- |
| `project.godot` | Godot 工程配置与自动加载设置 |
| `scenes/` | 游戏入口、主循环、场景和地图背景 |
| `entities/` | 玩家、敌人、子弹、经验球、手雷和拾取物 |
| `systems/` | 波次、武器、升级、输入、音效与反馈系统 |
| `core/` | 全局数据、事件、对象池与空间哈希 |
| `ui/` | 开始页、商店、HUD 与升级菜单 |
| `assets/` | 角色、场景、界面、字体和音频资源 |
| `outputs/` | 已保留的部分界面预览图 |
| `ASSET_CREDITS.md` | 素材来源与授权说明 |

数值调整主要从 `core/game_data.gd` 入手；实体的逐帧更新由 `scenes/main.gd` 集中调度，并使用对象池、空间哈希和远处敌人降频更新来控制开销。

## 开发与调试

项目支持启动参数。下例假设 Godot 可执行文件已配置为命令行中的 `godot`；否则请替换为本机可执行文件路径。

```sh
# 自动游玩，固定随机种子
godot --path . -- --autoplay --seed 12345

# 维持 420 只丧尸的压力场景，玩家无敌，并输出性能采样
godot --path . -- --autoplay --stress 420 --perf

# 开局生成首领，用于查看首领战斗表现
godot --path . -- --autoplay --boss
```

还可使用 `--profile` 输出主循环分段计时，或用 `--shot 1800` 在指定帧截图并退出。截图需要有窗口的渲染环境。无头模式会自动开启自动游玩，适合逻辑检查。

Godot 导入缓存 `.godot/`、本地 `work/`、`bin/` 和临时测试截图通过 `.gitignore` 排除，不纳入仓库。
